# First-party TODO parity with rpiv-todo

## Objective
Implement an Osdy-owned `todo` extension with behavioral parity against `@juicesharp/rpiv-todo@2.11.0` before any Osdy-specific customization. Pi conversation-branch tool-result snapshots, not `odd/tasks/*.md`, are the TODO authority. The ODD file and Engram mirror remain the separate orchestrator ledger; no automatic file synchronization.

## Scope and guardrails
- Stay on `feat/native-odd-todo`, based on `origin/main` at `f041ced`. Preserve unrelated dirty `odd/tasks/release-osdy-pi-1-3-0.md`, `odd/tasks/theme-aware-working-animation.md`, untracked `scripts/.gitignore` and `odd/tasks/native-odd-todo-smoke-tests.md`; do not stage them.
- Implement first-party behavior independently against the installed upstream 2.11.0 reference and its MIT-licensed public contract; do not bundle a second `todo` registration or copy upstream source without attribution.
- Match tool schema/actions and response snapshots (`create`, `update`, `list`, `get`, `delete`, `clear`), status transitions, dependencies, owner/metadata, session replay/isolation and UI lifecycle. Match `/todos` grouped output, above-editor live widget and collapse/overflow/refresh behavior. Include config/localization parity or document any evidence-based incompatibility before claiming complete parity. User-selected customizations after parity: keep completed widget rows visible with crossed-out subjects on subsequent turns; then present the read-only `/todos` list in a modal matching `/usage` without changing TODO authority.
- The old ODD-backed store and interactive `/todos` overlay are superseded by the user-selected source-of-truth change, not silently retained as another TODO authority. ODD orchestration still writes its own durable ledger and Engram separately.
- Test-first for deterministic behaviors; preserve usable intermediate commits. Work units about 400 authored lines each when coherent; never omit tests or compress code for a budget. Delivery strategy: previously selected feature-branch-chain, no push/PR/release authorized.
