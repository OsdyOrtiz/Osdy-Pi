# Clean Control Center UX

## Objective
Keep `/osdyconfig` orderly and responsive: paginated Themes, brief separated help, shared Codex quota cards, direct profile/Agent letters, and clearly spaced confirmations. User accepted both the first clean panel and the shared `/usage` dashboard, then requested `s` from quota `v` and confirmation spacing.

## Accepted behavior and safeguards
- Themes: at most 8 options/page, adaptive capacity, page counter and navigation/selection continuity.
- Account: one profile row; `v` usage, `s` switch, `d` default, applicable `c` clear; Enter usage fallback. Sensitive actions use Cancel-first confirmation.
- Quota: pure shared `/usage` dashboard content with the selected stored-profile snapshot/identity/timestamps; never copy active-account metadata or query during rendering/navigation. Unknown capacity stays unknown. Local token/cost analytics remain separate.
- Quota controls: `r` Refresh, `b` Back, and eligible `s` Switch for the pinned viewed inactive profile. Do not use quota action-row selection as switch identity. Existing projection/service owns availability, membership, stale session and idle rechecks; no new picker/auth/mutation path.
- Cancel/Esc from confirmation preserves quota profile, scroll and query state. Preserve editor hold, snapshot retention, refresh/back and owner guards. Modified/uppercase keys must not bypass lowercase Kitty-aware shortcuts or focus/modal/input/loading/query/save/busy gates.
- Agents: unique available typed `g` Gentle/`j` Joker shortcuts, full confirmation and stale/idle guards. `?` expands selected help.
- Layout: blank separators between sections, not every option. Rebudget pages/scroll on resize; gaps yield on small heights. Confirmation separates title, complete safety content, choices and instructions; wrap actual content and never enable acceptance by truncating safety text or hiding choices.
- Strict readable TypeScript; English artifacts; one writer. Preserve existing usage scheduler and services. Rollback only the relevant task's hunks, never whole dirty files.
